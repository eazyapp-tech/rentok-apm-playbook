# Security and privacy

This repository must not contain personal hiring records, customer data, credentials, or secrets.

## If sensitive information is found

1. Stop sharing or copying the affected file.
2. Tell the repository owner privately.
3. Remove the information from the current version and from Git history where required.
4. Rotate any exposed credential. Deleting a secret from the latest commit does not make it safe again.
5. Check Notion and other copies before closing the incident.

Do not open a public issue containing the sensitive value.

## Using AI tools safely

- Use approved tools and company accounts for company work.
- Do not place candidate, customer, employee, financial, credential, or other sensitive information into an unapproved AI tool.
- Remove identifying information when full detail is not needed.
- Check important facts, calculations, decisions, and actions before relying on an output.
- Independently verify high-consequence work and obtain the required human approval before acting.

AI may help do the work. The person who submits, shares, recommends, or acts on the output remains responsible for it.

For the normal storage boundary, read [Where information lives](docs/governance/where-information-lives.md).
